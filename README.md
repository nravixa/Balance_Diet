> **Pune's Premium Clean-Eating & High-Protein Diet Bowls**
> Designed & Engineered by **[NRAVIXA](https://nravixa.vercel.app)**

## ✨ Features (Inspired by `s-fvour.vercel.app`)

- 🥗 **Diet Bowl Menu Showcase**: Interactive categorized filter (*All*, *High Protein*, *Keto Bowls*, *Vegan & Green*, *Weight Loss Low-Cal*) with exact macro breakdowns (Calories, Protein, Carbs, Fats) and veg/non-veg tags.
- 📝 **Lead Information & Delivery Form**: Direct booking form capturing Customer Name, WhatsApp Number, Pune Delivery Area, Specific Landmark, Selected Bowl, and Time Window with instant WhatsApp order generation.
- 💬 **1-Click WhatsApp Direct Ordering**: Direct integration to `+91 9637173122` with pre-filled order payloads.
- 🗺️ **Pune Delivery Map**: Interactive Google Map integration showcasing delivery radius across Kothrud, Baner, Wakad, Viman Nagar, Hinjewadi, FC Road, and Shivajinagar.
- 🌊 **Smooth Scroll**: Powered by **Lenis** for 60FPS fluid navigation.
- ⚖️ **Indian Health & BMI Checker**: Customized calculator calibrated with Indian metabolic guidelines.
- 📱 **Mobile-First UX**: Responsive floating navigation pill, mobile drawer, and persistent sticky bottom quick action bar (`Call Us` & `Order on WhatsApp`).
- 🌐 **Social Proof**: Instagram (`@balance.diet.pune`), Facebook, and Google Verified Reviews presence.
- 🚀 **E-Commerce & App Ready**: Modular component architecture prepared for future cart management and mobile app packaging.
- ⚡ **Agency Credits**: Prominent branding for **NRAVIXA** (`https://nravixa.vercel.app`).

## 🛠️ Tech Stack

- **Framework**: Next.js 16.4.5 (App Router, Turbopack, Partial Prefetching)
- **Library**: React 19.3.0
- **Typography**: Playfair Display (Serif display headers) + Geist (Sans-serif)
- **Styling**: Tailwind CSS v4 (`@tailwindcss/turbopack`)
- **Smooth Scroll**: `@studio-freight/lenis` / `lenis`
- **Icons**: `lucide-react` & Custom SVGs
- **Language**: TypeScript 5 (Strict Mode)

## 🏁 Getting Started

```bash
# Clone and enter directory
cd "BALANCE DIET PUNE"

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the live site.
